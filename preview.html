Campaign Cleaner

Compact helper for safe Meta Ads imports: upload export file, clean system IDs/JSON noise, force statuses to PAUSED, download CSV.

Import Safety

Campaign ID Ad Set ID Stats Dates JSON Cleanup Safe Import PAUSED
  • Очищаются campaign/ad set/ad IDs, служебная статистика и чувствительные даты.
  • Safe import mode: все статусные поля принудительно приводятся к PAUSED.
  • Local processing: файл обрабатывается только в браузере, без отправки на сервер.
  • JSON cleanup: из JSON-like колонок удаляются импорт-конфликтные ключи.
  • Результат выгружается в CSV для прямого импорта.
Лог обработки:
Основной flow: upload file → clean → download CSV.
