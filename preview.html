Campaign Cleaner

Утилита для подготовки экспортированных кампаний к безопасному импорту без ошибок с сохранением ключевых данных и структуры.

Очистка

Поддерживаются форматы CSV и XLSX; файл на выходе сохраняется в формате входного файла.
Выбор режима Compact: Принудительно сводит структуру к 1-1-1. Подходит для кампаний с одинаковыми ad sets и объявлениями.

Smart: Удаляет только дубли и сохраняет уникальные ad sets / ads. Подходит для кампаний с разными настройками.

Full: Сохраняет оригинальную структуру кампании без схлопывания.
Лог обработки:

Памятка импорта

  • Креативы не переносятся автоматически: после импорта нужно вручную выбрать/загрузить креативы; для языковых версий — обновить креативы в каждом языке.
  • После импорта пиксель выбирается вручную.
  • По правилам FB публикация импортированной кампании возможна только после периода активности РК в течение нескольких недель.
  • После импорта кампании в FB может появиться список ошибок, который нужно закрыть; обычно это не влияет на успешность импорта.
  • Обработка выполняется локально в браузере, без отправки файла на сервер.
